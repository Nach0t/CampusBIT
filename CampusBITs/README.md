# campus_bit_app (CampusBIT)

Proyecto Flutter de **CampusBIT**. La documentación completa (funcionalidades, arquitectura, instalación, persistencia y pruebas) está en el [README principal del repositorio](../README.md).

Inicio rápido, desde esta carpeta:

```bash
flutter pub get
flutter run -d chrome     # o `flutter run` con un Android conectado
flutter test              # pruebas
```
